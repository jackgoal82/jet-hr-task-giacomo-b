# Fonti

Cartella per le note di ricerca sulle voci che compongono il calcolo RAL → netto. Un file per argomento, con link alla fonte originale e i numeri/formule effettivamente usati nel codice.

File attesi (da creare durante la ricerca):

- `irpef.md` — scaglioni e aliquote IRPEF, detrazioni da lavoro dipendente
- `inps.md` — aliquota contributiva a carico del dipendente
- `addizionali.md` — addizionale regionale Lombardia e comunale Milano
- `trattamento-integrativo.md` — ex bonus Renzi / cuneo fiscale, soglie e importi

Ogni nota dovrebbe riportare: fonte (URL, ente, data di pubblicazione/aggiornamento), anno fiscale a cui si riferisce, e il valore/formula estratto.
